# _reference

هذا المجلد مخصص لاستقبال المواد المرجعية الحقيقية لمشروع موقع جواهر الخير قبل بدء التنفيذ (Sprint 1). لا يحتوي على أي أكواد أو بيانات وهمية، وهو فقط بنية تنظيمية فارغة بانتظار المحتوى الفعلي.

## brand/
مواد الهوية البصرية الرسمية: الشعار، دليل الهوية، الخطوط، الألوان، ومراجع بصرية سابقة.

## products/
معلومات وأصول المنتجات الحقيقية: كتالوجات، ملفات Excel/CSV/PDF، صور المنتجات (لكل فئة)، صور التغليف، ومراجع أخرى.

## business/
بيانات الشركة الرسمية: معلومات الشركة، بيانات التواصل (هاتف/واتساب/بريد)، وحسابات التواصل الاجتماعي.

## content/
المحتوى الموجه للعميل: من نحن، قصة العلامة، وصف الفئات، نصوص المنتجات، الأسئلة الشائعة، ومحتوى آخر للموقع.

## policies/
السياسات الرسمية/القانونية: الشحن، الإرجاع والاسترداد، الخصوصية، الشروط، وسياسات الدفع.

## experience/
أصول ومراجع لصفحة "تجربة المنتج" المستقبلية لكل فئة (تمور، عسل، زيوت، مكسرات، سمن)، بما في ذلك مراجع بصرية/فيديو/حركة.

## migration/shopify/
ملفات تصدير Shopify أو مواد الترحيل التاريخية فقط — Shopify لن يكون جزءًا من التشغيل الفعلي للموقع مستقبلاً.
